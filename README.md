We aimed to developed an online tutoring platform named EduNexus. Student, Tutor and Admin will be the main user of the platform. Students are able to select their course, request tutor booking session, view their own progress and explore study materials. Tutor are able to update their own profile, accept/reject the request bookings from students and upload the study materials. Admin can manage to add/delete students/tutors' account and delete the old study materials that uploaded by the tutors to keep the information updated. 

We used Scrum method to complete the work with using Sprint 1 and Sprint 2 through Trello. In the planning part, we gather the user requirements (functional and non-functional) from the product owner and after that we started to plan using the Agile Method. 

We design the Class Diagram, Use Case Diagram as references to visualize the structure and components to show user interactions clearly. We start design our platform using Figma with sketch our wireframe first, then we complete our mock ups.
